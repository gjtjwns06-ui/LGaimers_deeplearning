# R 전용 보완 DL 및 v22 실행 결과

실행일: 2026-08-27

## 결론

단순 평균 대신 v21의 R 오차와 다른 방향을 내는 `combined-signal DCNv2`를
조건부 전문가로 추가했다. 새 확률을 전 구간에 섞지 않고, 전진 검증에서 반복
개선된 두 상태에만 적용한다.

```text
p_v22 = p_v21 + w(불확실도, DL 방향) × (p_combined_DL - p_v21)
```

- 적용 범위: `game_type=R`
- `|p_v21-0.5| > 0.05`이고 새 DL이 위쪽일 때: 최대 30%
- `0.025 < |p_v21-0.5| <= 0.05`이고 새 DL이 아래쪽일 때: 제한 가중치
- 나머지 R 및 모든 F: v21과 동일
- 테스트 행 간 집계·정렬·rolling: 없음
- 추론 입력: 현재 행과 train에서 고정한 전년도 룩업만 사용

## 후보 실험

| 후보 | 2024 R 단독 점수 | v21 보완 판정 |
|---|---:|---|
| 최초 R-only TabM | 524.60 | 직접 혼합 oracle 가중치 음수, 기각 |
| TabM + rate basis + 전년도 TE | 604.33 | 후반 보완 이득 사실상 0, 기각 |
| TrackMan DCNv2 조건부 | - | 홀드아웃 Brier -0.00000120, 너무 작아 주력 기각 |
| combined-signal DCNv2 조건부 | 647.49 | 내부·후반·월별 모두 개선, 채택 |

채택 모델은 비선형 rate basis, 전년도 pitcher/batter/platoon/count target
encoding, reverse/middle/ball/strike 보조 head를 사용한다. 최종 모델은 고정된
3 epoch로 2019–2024 전체에 재학습했다.
